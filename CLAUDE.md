# Рабочий репозиторий

Здесь хранятся задачи и заметки, которые ведутся в Claude Code с разных устройств.

## Как работать
- Каждая задача лежит в своей папке внутри `tasks/`.
- В начале работы читай только `STATUS.md` нужной задачи, не всю историю.
- В конце сессии обнови `STATUS.md`: что сделано, что дальше.
- Шаблон для новой задачи: `_templates/STATUS.md`.

## Настройка другого устройства
- Пошаговая инструкция: `SETUP.md`.

## Язык
- Заметки и ответы по умолчанию на русском.

## Что нельзя коммитить
- Пароли, API-ключи, токены. Для них используй `.env` (он в `.gitignore`).
